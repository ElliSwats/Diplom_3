# Diplom_3
### Автотесты для проверки UI сервиса Stellar Burgers: https://stellarburgers.nomoreparties.site/


### Реализованные тестовые сценарии


#### Тестирование основной функциональности:
- переход по клику на «Конструктор» (test_switch_to_constr_success)
- переход по клику на раздел «Лента заказов» (test_switch_to_order_feed_success)
- если кликнуть на ингредиент, появится всплывающее окно с деталями (test_click_to_ingredient_open_window_success)
- всплывающее окно закрывается кликом по крестику (test_open_close_ingr_window)
- при добавлении ингредиента в заказ счётчик этого ингредиента увеличивается  (test_current_totalizer_basket_ingr)

#### Тестирование связанное с созданим заказа:
- при создании нового заказа счётчик «Выполнено за всё время» увеличивается (test_increasing_counter_all_time)
- при создании нового заказа счётчик «Выполнено за сегодня» увеличивается (test_increasing_counter_today)
- после оформления заказа его номер появляется в разделе «В работе» (test_order_number_listed_in_progress)

### Структура проекта

- `data.py` - содержит вспомогательные данные для тестов.
- `conftest.py` - настройки и фикстуры для тестов.
- `locators/` - локаторы страниц.
- `pages/` - методы.
- `test/` - тесты UI.
